# youtube-noshorts

Personal SideStore/AltStore source hosting YouTube with Shorts, comments,
like/dislike controls, and video view counts removed.

Add this source URL in SideStore:

```
https://raw.githubusercontent.com/rrogerc/youtube-noshorts/main/noshorts-nostats2.json
```

Install over the existing app to preserve its data and sign-in. The older sources
and release IPAs remain available as fallbacks.
